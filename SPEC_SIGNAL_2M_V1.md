# Техническое задание Сигнал 2М LMZ — актуальная версия 0.3

Дата: 23 октября 2026 года. Цель обновления: версия 0.3 для Windows x64, формат VST3.

«Сигнал 2М» — инструмент LMZ с запуском от MIDI-нот, «Ленинградский модульный звук». Плагин воспроизводит панель раннего аппаратного варианта по предоставленным фотографиям, основной генератор с LFO и добавленный делей с режимом Oscillation. Каждая MIDI-нота заново запускает модель; её длительность задаёт время звучания. При отпускании гаснет весь тракт, включая Oscillation, с коротким release до 5 мс. MIDI 60 нейтрален относительно ручки VCO; остальные ноты транспонируют её частоту. LFO и delay не транспонируются.

Пользователь самостоятельно проверит внешний вид и работу в FL Studio. Задача разработки — передать первую собранную версию с полноценным интерфейсом, техническими проверками и инструкцией по установке. Совпадение звука с конкретным экземпляром по записи пока не проверялось.

## Источники устройства

Основной узел задан приложенной схемой MFOS Alien Screamer Noise Box, Designed by Ray Wilson. В ней VCO создаёт звук, LFO управляет частотой VCO, два переключателя формируют и выбирают модулирующий сигнал, а Sync Effect добавляет сброс цикла VCO от LFO.

Делей задан приложенной схемой Deep Blue, versão 2.0, Stallion Custom Effcs, с микросхемой PT2399. По объяснению пользователя этот узел соединён с генератором и дополнен кнопкой Oscillation. Объединённая разводка и подключение добавленной кнопки на двух исходных схемах не показаны.

Восстановление функций опирается на схемы, их первичную документацию и последние объяснения пользователя. Конкретные допущения первой цифровой модели фиксируются отдельно от подтверждённых свойств прибора.

## Рабочие органы управления

| Элемент панели | Требуемое действие | Параметр автоматизации |
| --- | --- | --- |
| VCO Freq | Плавно меняет частоту основного звукового генератора | Непрерывный |
| LFO mod | Меняет глубину воздействия LFO на частоту VCO | Непрерывный |
| LFO freq | Меняет частоту LFO | Непрерывный |
| Master | Меняет общий выходной уровень | Непрерывный |
| Mix | Меняет количество эха в выходном сигнале | Непрерывный |
| Delay | Меняет время задержки между повторами | Непрерывный |
| Repeats | Меняет обратную связь и затухание повторов | Непрерывный |
| Левый нижний тумблер с обозначением волны | Участвует в выборе и формировании сигнала LFO | Дискретный |
| Средний нижний тумблер с обозначениями волн | Участвует в выборе и формировании сигнала LFO | Дискретный |
| Sync / Off | Включает и выключает эффект синхронизации генераторов по исходной схеме | Два состояния |
| Oscillation | Включает и выключает режим незатухающих повторов в петле делея | Два состояния для первой сборки |

Все семь ручек и четыре действующих переключаемых элемента доступны для штатной автоматизации DAW. Sync относится к работе LFO и VCO внутри инструмента; управление темпом проекта из этой подписи не следует.

Точное соответствие положений двух тумблеров состояниям S1 и S2 требуется разобрать по исходной схеме и фотографиям. Графически сохраняются оба отдельных тумблера.

Oscillation по объяснению пользователя усиливает или замыкает обратную связь делея для бесконечных повторов. При активном режиме повторы не должны вести себя как обычный быстро затухающий хвост. Цифровая модель петли должна оставаться численно устойчивой и давать конечные значения выходных отсчётов.

## Допущения для первой сборки

Следующие детали выбираются для версии 0.3 и не выдаются за подтверждённую разводку конкретного экземпляра:

- Oscillation работает с фиксацией: одно нажатие включает режим, повторное выключает. Пользователь ещё не подтвердил, является ли аппаратная кнопка удерживаемой. Это поведение легко изменить после первой проверки.
- При отсутствии объединённой схемы используется обоснованное соединение выходного сигнала генератора с узлом делея, регулируемым подмешиванием эха и общим Master. Точки соединения и закон Mix фиксируются в техническом решении.
- Точные диапазоны и начальные значения ручек, кривые регулирования, формы сигналов, параметры Sync и модель окраски PT2399 выбираются после разбора схем. Приближения описываются в отчёте о сборке.
- Первая сборка ориентирована на Windows x64. Выпуск других платформ не является условием выдачи версии 0.3.

Оркестратор принимает технические решения в этих пределах самостоятельно. Потребность уточнить поведение оригинала не должна останавливать создание работоспособной первой версии, если возможно явно описать разумное приближение.

## Графический интерфейс

Основной референс — signal2m-panel-overview.png. Интерфейс представляет прямоугольную панель в виде сверху с расположением элементов по этой фотографии:

- Верхняя строка: VCO Freq, LFO mod, LFO freq, Master.
- Средняя строка: Mix, Delay, Repeats и кнопка Oscillation справа.
- Нижняя область: два тумблера формирования сигнала, Sync / Off, название «Сигнал 2М» и фирменный знак.
- Вертикальная колонка индикаторов и верхняя область разъёмов сохраняются визуально.

Поверхность чёрная с горизонтальной фактурой. Сохраняются белые подписи, рамки со скруглёнными углами, деления и цифры шкал. Фирменный знак — волнообразный графический рисунок и надпись «Ленинградский модульный звук» в нижней правой части, как на текущем референсе.

На всех семи местах ручек используются законченные ручки по signal2m-knob-angle.png и signal2m-knob-top.png: чёрный рельефный корпус, серебристая круглая верхушка с концентрической фактурой и светлая указательная метка. Открытые штоки на общей фотографии отражают стадию сборки прибора и не являются видом готовых ручек плагина.

Тумблеры воспроизводятся по их отдельным фотографиям, включая металлический рычаг и характерную шайбу. Кнопка Oscillation воспроизводится по крупным планам. Действующие элементы меняют положение при ручном управлении и автоматизации.

Переключатель power, DC9V и верхние гнёзда остаются статическими. Серебряные сердцевины вращаются вместе с ручками. По новой просьбе пользователя верхняя лампа показывает LFO, а колонка индикаторов движется снизу вверх со сдвигом половины периода. Без активной ноты индикаторы тёмные. Их рисунок — простое приближение; схема аппаратной подсветки не подтверждена. Надпись stereo out сама по себе не определяет отдельный режим стереообработки.

Первая версия уже содержит оформленную панель по референсу. Оценку сходства и последующие пожелания по визуалу даст пользователь.

## Автоматизация и состояние

Действующие параметры имеют постоянные идентификаторы, понятные имена и корректные непрерывные или дискретные типы. Ручное изменение и автоматизация используют один путь управления звуковой моделью. Автоматизация должна влиять на звук и при закрытом окне плагина.

Настройки действующих органов управления сохраняются в состоянии VST3 и восстанавливаются при загрузке. Наличие штатного меню автоматизации по правому клику используется, когда его предоставляет хост; параметры остаются доступны и через обычный список автоматизации DAW.

Первая цифровая модель не должна зависеть от частоты обновления интерфейса. При изменении частоты дискретизации и размера аудиоблока сохраняется корректное время работы генераторов и задержки.

## Техническая проверка и проверка пользователя

Независимый проверяющий проверяет исходники, воспроизводимость сборки, параметры и состояние, DSP и содержимое дистрибутива. Разумный минимальный набор включает:

1. Тишину без MIDI, точные позиции запуска/отпускания, retrigger с чистой историей delay и транспозицию note60→72; реакцию на VCO Freq, LFO mod и LFO freq.
2. Различие режимов двух тумблеров и Sync согласно выбранной модели.
3. Работу Mix, Delay, Repeats, Master и включения с выключением Oscillation.
4. Устойчивость обратной связи, отсутствие NaN и Inf, корректность после сброса и повторной подготовки обработки.
5. Обработку при 44,1 и 48 кГц и разных размерах блока; независимость нескольких экземпляров.
6. Сохранение с восстановлением параметров и их изменение через интерфейс параметров хоста. VST3-validator или аналогичный технический хост применяется, когда доступен в выбранном стеке.
7. Совпадение проверенной сборки с содержимым выдаваемого архива.

Пользователь самостоятельно устанавливает плагин, проверяет его в FL Studio и оценивает внешний вид. Разработка не требует запуска, управления или визуального тестирования FL Studio агентами. Эти ручные проверки отмечаются как ожидающие пользователя и не препятствуют выдаче технически проверенной версии 0.3.

## Выдача обновления

Распакованная копия обновляется в существующей папке dist/Signal2M-v0.1-Windows-x64. Новый архив: dist/Signal2M-v0.3-Windows-x64.zip с полным пакетом Signal2M.vst3 и краткой русской инструкцией. Установщик для первой выдачи не требуется. Пользователю не нужны компилятор и SDK для запуска готовой сборки; необходимые runtime-зависимости должны быть учтены в поставке или явно указаны.

Пакет VST3 копируется целиком. Инструкция указывает стандартную папку Windows C:\Program Files\Common Files\VST3 и повторное сканирование плагинов. Установку в системные папки выполняет пользователь.

В проекте остаются исходники, зафиксированные версии зависимостей и инструкции для повторной сборки. В отчёте перечисляются выполненные технические проверки, принятые допущения и ручные проверки пользователя. Текстовые файлы сохраняются в UTF-8.

## Уточнения внешнего вида 25 октября 2026, версия 0.3

Точный рисунок LMZ и обе оригинальные строки букв векторизуются по фотографии, без приблизительной новой волны и без системного шрифта. Тумблеры используют два отдельных SVG с общим креплением; прежние ручки сохраняются. Колонка LED синяя, верхний LED белый, каждый получает мягкий цветной ореол.

Вся нижняя правая область логотипа открывает карточку над затемнённой панелью с призывом приобрести синтезаторы LMZ, ссылкой https://t.me/lenmodzvuk и двумя неактивными донатными местами. Ссылка открывается по явному клику, фон и свободная часть карточки/Close/Esc закрывают её без передачи клика органам управления. Новых звуковых функций или DAW-параметров это обновление не добавляет.

## Дополнение: ручные обновления и BETA

В карточке LMZ требуется кнопка «Проверить обновления». Только она запускает фоновый ограниченный по времени запрос к публичной таблице Signal2M updates, Distr!A1:B1, gid=0. A1 содержит удалённую версию, B1 — свободно изменяемый владельцем полный URL страницы. Плагин сравнивает числовые компоненты со своей версией сборки 0.3.0, оставленной по прямому указанию пользователя. Таблица не изменяется разработкой.

Показываются «Проверяем…», «Обновлений нет», «Доступна версия X» с отдельной ссылкой «Перейти к обновлениям», либо «Не удалось проверить обновления. Попробуйте позже». Ошибка и новая проверка убирают прошлую ссылку; переход в браузер происходит по явному нажатию. Скачивание и установку выполняет пользователь. Аудиопоток сеть не вызывает. На mainpanel слева сверху небольшая BETA для 0.x; начиная с 1.0.0 скрывается автоматически.
