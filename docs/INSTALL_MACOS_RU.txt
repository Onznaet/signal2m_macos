LMZ Signal 2M — версия 0.3.1, macOS Universal, VST3

СОВМЕСТИМОСТЬ
Один пакет Signal2M.vst3 содержит arm64 для Apple Silicon и x86_64 для Intel.
Цель компиляции: macOS 11.0+ на Apple Silicon и macOS 10.15+ на Intel.
DAW должна поддерживать VST3 instruments. Имя инструмента — LMZ Signal 2M.
Физическое имя пакета — Signal2M.vst3. Форматы AU и Standalone не поставляются.
Проверка в конкретной DAW и на минимальных версиях macOS выполняется отдельно.

СТАТУС ПЕРВОЙ MAC-СБОРКИ
Рецепт по умолчанию создаёт локальную ad-hoc подпись для технической проверки.
Это не Developer ID и не нотариализация Apple. Фактический тип подписи указан
в MANIFEST.json; notarization: not-performed означает, что нотариализации не было.
При блокировке загруженного извне пакета macOS сохраните текст сообщения для
разработчика. Глобальное отключение Gatekeeper не требуется этим рецептом.
Локальную сборку на Mac можно получить командой bash tools/build_macos.sh;
подробности находятся в BUILD_MACOS_RU.md исходного проекта.

РУЧНАЯ УСТАНОВКА
1. Закройте DAW и её процессы сканирования плагинов.
2. Распакуйте Signal2M-v0.3.1-macOS-Universal.zip штатной программой macOS.
3. В Finder выберите «Переход» → «Переход к папке» и откройте:
   ~/Library/Audio/Plug-Ins/VST3
   Если папки VST3 нет, создайте её внутри этой пользовательской папки.
4. Скопируйте Signal2M.vst3 целиком в VST3. Не извлекайте файл из
   Contents/MacOS, не меняйте расширение пакета и не копируйте Windows VST3.
   Общесистемный вариант /Library/Audio/Plug-Ins/VST3 используется только
   по отдельному решению владельца Mac; эта инструкция использует папку пользователя.
5. Запустите DAW, выполните повторное сканирование VST3 и выберите
   LMZ Signal 2M как инструмент. Добавьте MIDI-ноту: без нот выход молчит.

Пакет и его внутренние файлы после подписи не редактируют. Инструкции,
MANIFEST.json, licenses и artwork лежат рядом с Signal2M.vst3 в доставке.
Их не нужно помещать внутрь подписанного пакета.

ОБНОВЛЕНИЕ И УДАЛЕНИЕ
Перед заменой закройте DAW. Сохраните предыдущий пакет в своей резервной папке
и замените только Signal2M.vst3, затем повторите сканирование. Другие плагины
и их файлы не удаляются. Для удаления закройте DAW и удалите только свой
~/Library/Audio/Plug-Ins/VST3/Signal2M.vst3.
Скрипты проекта не выполняют установку, замену и удаление в этих папках.

ОСНОВНЫЕ ПРОВЕРКИ В DAW
- Нота MIDI 60 — нейтральная опора: частоту задаёт VCO Freq. Нота на октаву
  выше удваивает частоту; название октавы C зависит от настроек DAW.
- Каждая новая нота запускает VCO, LFO, фильтры и историю эха заново.
  Отпускание ноты гасит весь звук максимум за 5 мс.
- Инструмент монофонический; приоритет имеет последняя удерживаемая нота.
  Velocity используется как включение/выключение.
- Master в ноль глушит выход. All Sound Off и reset гасят удерживаемые ноты.
- Проверьте все семь ручек, четыре действующих переключателя, автоматизацию,
  сохранение/открытие проекта, повторное открытие окна и отображение SVG/LED.
- Проверьте проект предыдущей версии с теми же параметрами и MIDI-нотами.
  Идентификаторы плагина и параметров сохранены от Windows-издания.

КАРТОЧКА LMZ И ОБНОВЛЕНИЯ
Область логотипа открывает карточку LMZ; Esc и «Закрыть» закрывают её.
Ссылка производителя https://t.me/lenmodzvuk открывается браузером по нажатию.
При первом открытии окна экземпляра один раз выполняется фоновая проверка
обновлений. Закрытие и повторное открытие того же окна не повторяет запрос.
«Новая версия» под логотипом открывает ту же карточку. Ручная кнопка
«Проверить обновления» позволяет повторить запрос.
Mac читает отдельный лист Google-таблицы Signal2M updates: gid=640439888.
A1 — версия для Mac, B1 — адрес страницы обновления для Mac. Лист Windows
с gid=0 этой сборкой не используется. Ссылка из B1 открывается только после
нажатия. Загрузка и установка обновления выполняются пользователем.
При ошибке сети или данных аудио продолжает работать; запрос имеет общий
лимит около 8 секунд. Автоматических повторов по таймеру нет.

Для запуска готового VST3 Python, Git, CMake, Xcode, JUCE и SDK не нужны.
Запишите модель Mac, архитектуру, версию macOS, DAW и её режим запуска
(нативный/под Rosetta), чтобы результат проверки можно было воспроизвести.
