LMZ Signal 2M — 0.4.0 RELEASE, macOS Universal, VST3

ГОТОВЫЙ ПАКЕТ
Signal2M-v0.4.0-macOS-Universal.zip распаковывается в один Signal2M.vst3.
В Finder это пакет плагина; его копируют целиком. Архитектуры: arm64 для
Apple Silicon и x86_64 для Intel. Целевые минимумы: macOS 11.0 / 10.15.
Имя инструмента в DAW — LMZ Signal 2M. Для готового VST3 Python и Xcode не нужны.
Эта инструкция находится в исходном проекте и не добавляется в delivery ZIP.

УСТАНОВКА
1. Закройте DAW и процессы сканирования плагинов.
2. Распакуйте ZIP штатной программой macOS.
3. В Finder выберите «Переход» → «Переход к папке»:
   ~/Library/Audio/Plug-Ins/VST3
   При необходимости создайте VST3 в этой пользовательской папке.
4. Скопируйте Signal2M.vst3 целиком. Перед заменой сохраните предыдущий пакет
   в резервной папке. Файл Contents/MacOS/Signal2M отдельно не вынимают.
5. Откройте DAW, повторно просканируйте VST3 instruments и добавьте LMZ Signal 2M.
   До первой MIDI-ноты инструмент молчит; при включённой P после неё остаётся эхо.

Сборка содержит VST3. AU и Standalone в неё не входят. Bundle и его внутренние
ресурсы после подписи не редактируют. Legal/notices/licenses и Build/manifest/
native-test-results/provenance уже находятся внутри Contents/Resources;
отдельные инструкции или artwork рядом с плагином не нужны.

ВЕРСИЯ 0.4.0
Сохранены исходные идентификаторы и 14 параметров текущего Windows-издания.
T под LFO freq включает привязку LFO к BPM, T под Delay — привязку времени эха.
Эти кнопки независимы от аппаратного Sync / Off, который связывает генераторы.
В режиме T ручка выбирает длительности и триоли. При отсутствии BPM используется
последнее корректное значение, первоначально 120 BPM.
Новый экземпляр: LFO T выключена, Delay T и P включены.

P под Mix включает Post: нотная огибающая управляет генератором до эха,
а Delay/Repeats/Oscillation продолжаются после отпускания ноты и между нотами.
При выключенной P действует прежнее гашение всего звука при отпускании.
Master в ноль глушит весь выход. Stop, reset и MIDI All Sound Off очищают хвост.
Нота 60 остаётся нейтральной опорой для частоты ручки VCO Freq.

КАРТОЧКА LMZ
Логотип открывает карточку. Telegram: https://t.me/lenmodzvuk
Донатные кнопки читаются в фоне из общего листа Don gid=1525027926, A1/A2.
Пустой или неверный адрес скрывает соответствующую кнопку. Ссылки открываются
только по нажатию. Переводы и платежи из плагина автоматически не выполняются.

Mac обновления читаются из отдельного gid=640439888, A1 — версия, B1 — страница.
Windows-лист gid=0 для Mac обновлений не используется. Сборка не меняет таблицу.
Автоматическая проверка обновлений запускается при первом открытии редактора,
ручная кнопка позволяет повторить её. Аудио не запускает сетевые запросы.

ПОДПИСЬ И ПРИЁМКА
В Mac RELEASE надпись BETA отключена настройкой сборки. По умолчанию пакет
подписывается ad-hoc; Developer ID и нотариализация Apple отсутствуют.
При блокировке macOS сохраните точный текст сообщения разработчику.
Глобальное отключение Gatekeeper не входит в установку.

Новый нативный прогон 0.4.0 должен подтвердить техническую сборку. Ручная
приёмка в DAW, внешний вид, автоматизация и реальные проекты проверяются
на Mac пользователя. Load commands с минимальными ОС не заменяют запуск
на macOS 10.15 Intel и 11.0 Apple Silicon.
