LMZ Signal 2M 0.3.1 — готовый macOS Universal VST3

ГОТОВАЯ ПОСТАВКА
dist-macos/Signal2M-v0.3.1-macOS-Universal.zip
Размер: 5 767 813 байт.
SHA-256:
d916a9fdbc52578769a74ad1e58ee8f5faa7c57dc767548344f4e6ed28e9aedf

Пакет содержит arm64 для Apple Silicon и x86_64 для Intel.
Имя в DAW — LMZ Signal 2M, физический пакет — Signal2M.vst3.
Готовому плагину Xcode, Python, Git и компилятор не нужны.

НАТИВНЫЕ РЕЗУЛЬТАТЫ
Run5 завершился успешно на Apple Silicon и Intel: по 9/9 технических тестов,
проверка подписи, ZIP и загрузка извлечённого VST3 независимым host.
https://github.com/Onznaet/signal2m_macos/actions/runs/40419330616
Исходный commit: c3dc36f91ade3c6e5194ffceccd5a009faeab2ae

Основная доставка выше — Universal-сборка с нативной проверкой arm64.
Intel job нативно проверил отдельную Universal-сборку того же commit;
у двух ZIP разные хеши. Основная доставка содержит обе архитектуры.
В GitHub Actions основной архив находится внутри artifact
Signal2M-macOS-native-arm64, в каталоге dist-macos. Артефакты хранятся 7 дней.

УСТАНОВКА НА MAC
1. Закройте DAW и её процессы сканирования плагинов.
2. Распакуйте Signal2M-v0.3.1-macOS-Universal.zip штатной программой macOS.
3. В Finder выберите «Переход» → «Переход к папке»:
   ~/Library/Audio/Plug-Ins/VST3
   Если VST3 отсутствует, создайте её в этой пользовательской папке.
4. Скопируйте Signal2M.vst3 целиком в VST3. Внутренний файл Contents/MacOS
   отдельно не копируют. Перед заменой предыдущего пакета сохраните его копию.
5. Запустите DAW, повторно просканируйте VST3 и выберите LMZ Signal 2M.
   Добавьте MIDI-ноту: без нот инструмент молчит.

Подробности — docs/INSTALL_MACOS_RU.txt в проекте и INSTALL_MACOS_RU.txt
рядом с плагином в готовой поставке. Требуется хост с поддержкой VST3 instruments.
Эта поставка содержит VST3; AU для Logic Pro в неё не входит.

ПОДПИСЬ И ГРАНИЦЫ ПРОВЕРКИ
Пакет имеет ad-hoc подпись. Developer ID и нотариализация Apple отсутствуют.
Поведение скачанного пакета и разрешений macOS проверяется на Mac пользователя;
глобальное отключение Gatekeeper не входит в установку.
Целевые минимумы: macOS 10.15 Intel / 11.0 Apple Silicon. Load commands обоих
срезов проверены, но запуск на этих минимальных ОС отдельно не выполнялся.
CI работал на macOS 15. Внешний вид, работа редактора и приёмка в DAW ещё нужны.

ДОКУМЕНТАЦИЯ И СНИМОК СБОРКИ
Актуальный REVIEW_MACOS_REPORT.md находится в репозитории. Отчёт внутри
доставленного ZIP сохраняется как исторический снимок на момент сборки;
он может содержать прежние pending-статусы. Готовый ZIP после проверки
не редактировался.

ПОВТОРНАЯ СБОРКА
Для самостоятельной сборки нужны Xcode Command Line Tools, Git и нативный
Python 3.9+ с pip. Из корня исходников:
   bash tools/build_macos.sh
Рецепт не устанавливает плагин и не открывает DAW.
Signal2M-v0.3.1-macOS-SOURCE.zip — исходный комплект для пересборки.
