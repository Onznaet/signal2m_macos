LMZ Signal 2M 0.3.1 — исходный комплект для первой сборки на Mac

ЭТО ИСХОДНИКИ, А НЕ ГОТОВЫЙ VST3.
Signal2M-v0.3.1-macOS-SOURCE.zip нельзя копировать в папку плагинов DAW.
Готовый Universal-плагин появится после успешной сборки и проверок на Mac.

НА MAC ДРУГА
1. Распакуйте SOURCE.zip в отдельную обычную папку с правами записи.
2. Потребуются Xcode Command Line Tools с macOS SDK, Git и нативный Python 3.9+
   с pip. Если Xcode tools отсутствуют, установите их штатно и дождитесь окончания.
   Рецепт не устанавливает глобальные пакеты, Homebrew или Rosetta.
3. Откройте Terminal в распакованной папке и выполните:

   bash tools/build_macos.sh

   Команда скачает закреплённые зависимости в эту папку, соберёт обе архитектуры,
   проверит нативный срез текущего Mac, подпишет пакет локальной ad-hoc подписью
   и подготовит ZIP. Команда не устанавливает плагин и не открывает DAW.
4. После успеха ожидаются:

   dist-macos/Signal2M-v0.3.1-macOS-Universal.zip
   dist-macos/Signal2M-v0.3.1-macOS-Universal.zip.sha256
   build-macos/native-test-results.json
   build-macos/Testing/Temporary/LastTest.log

5. Сохраните результаты и при ошибке текст Terminal. Важны модель Mac, версия
   macOS и архитектура. Одна машина проверяет свой нативный срез; полноценная
   проверка второго среза требует Mac другой архитектуры или облачного runner.

ПРОВЕРКА ПЛАГИНА
Установку полного Signal2M.vst3 и запуск выполняйте по docs/INSTALL_MACOS_RU.txt.
Это VST3 для хоста с поддержкой VST3. В Logic Pro используется другой формат AU;
эта первая поставка AU не добавляет.
Цель сборки: macOS 10.15+ Intel / macOS 11+ Apple Silicon. Запуск на самых ранних
версиях ОС пока не подтверждён одной только сборкой на современном Mac.

Первая техническая сборка использует ad-hoc подпись. Это не Developer ID и не
нотаризация Apple; загрузка скачанного плагина может потребовать штатного ручного
разрешения macOS. Не отключайте Gatekeeper глобально.

ОБЛАЧНЫЙ МАРШРУТ
Локально подготовлен .github/workflows/macos.yml для Intel и Apple Silicon
GitHub-hosted runners. Он не запускался и не публиковался из этого Windows-сеанса.
Для запуска нужен согласованный репозиторий и действующая авторизация владельца.
Выгрузка результатов в Actions задаётся явным параметром workflow.

ОБНОВЛЕНИЯ
Mac читает отдельный лист gid=640439888 той же открытой Google-таблицы.
A1 — последняя версия, B1 — страница обновлений. Windows сохраняет gid=0.
Таблица разработчиком не изменялась. Внешний вид и управление — текущая 0.3.1.

ДОКУМЕНТАЦИЯ

docs/BUILD_MACOS_RU.md — подробный рецепт.
REVIEW_MACOS_REPORT.md — фактически выполненные и ожидающие Mac проверки.
SOURCE_MANIFEST.json — SHA-256 файлов исходного комплекта, без пользовательских
пресетов, credentials, локальных инструментов и результатов Windows-сборки.
