**Независимая техническая проверка macOS Release 0.4.0 — подготовка исходников**

Дата: 28 октября 2026 года. Подготовлены независимые host/package проверки для переноса принятого Windows 0.4.0 на macOS. **Нативная сборка, исполнение десяти CTest, проверка подписи и выпуск Mac 0.4.0 на момент этой редакции ещё не выполнены.** Здесь не заявляется готовый Mac 0.4.0 artifact или native PASS. Работа велась на Windows, без Apple SDK, native Editor, DAW и удалённых действий проверяющего. Существующие Windows dist и проверенная Mac 0.3.1 не изменялись.

`Tests/ReviewerMacVst3Checks.cpp` обновлён на версию 0.4.0 и 14 параметров. Сохранены настоящий CoreFoundation loader, проверка Info.plist и физического Signal2M.vst3, разрешение относительного executable URL через CFURLCopyAbsoluteURL, bundleEntry/GetPluginFactory/bundleExit. Processor/controller/compatibility идентичность сравнивается как семантические FUID с учётом platform TUID layout; ожидаются прежние LMZ, Lmzz/Sg2m и sound.lmz.signal2m.

В общий host перенесены проверки исправленного Windows host, который ранее прошёл 4582 утверждения. Исходники Instance и всех исполняемых audio/state сценариев побайтно сверены с Windows-версией. Проверяются прежние 11 IDs, порядок, ranges/skew/defaults, три новых automatable bool и свежие состояния LFO T=off, Delay T=on, Post=on. Legacy-проверки явно выключают T/T/P. Настоящий 616-байтовый fixture 0.1 загружается в экземпляр с новыми флагами on; ожидается восстановление отсутствовавших режимов в off.

Добавлены meaningful BPM/straight/triplet timing, PPQ/time-signature independence, начальные 120 BPM и last-good fallback, clamp 10–999 BPM, retrigger, Post tails, CC120/123, transport panic, Post→Pre fade, реальная 24-секундная задержка и конечный/бесконечный VST3 tail. LFO timing измеряется по audible edge cadence. Сохранена корректная one-sample привязка backward difference; carrier RMS не используется вместо измерения музыкального периода. Это перенесённые assertions, а не объявление их Mac runtime результата.

На Windows выполнен C++17 syntax check с настоящими VST3 SDK headers и declaration-only CoreFoundation stub: **PASS с -Wall -Wextra -Werror**. Evidence: `build/mac/reviewer040/host-mock-syntax.json`. Такой check не проверяет Apple SDK, Mac ABI/link, Foundation runtime или загрузку bundle. Неиспользуемый helper удалён; исполняемые проверки не ослаблялись.

`Tests/ReviewerMacPackageChecks.py` сохраняет строгий прямой разбор Universal Mach-O: ровно arm64 и x86_64, MH_BUNDLE, minimum OS 11.0/10.15, границы и load commands, системные Apple dependencies и наличие signature structures. Проверяются Mac update gid640439888, Donation gid1525027926 A1:A2, версия 0.4.0, class CIDs, новые UI/parameter strings и отсутствие compiled BETA badge literal. Cryptographic signature в native режиме проверяется отдельным codesign; offline mode не объявляет подпись проверенной.

Новый ZIP-контракт требует единственный корневой Signal2M.vst3, целый Finder bundle. __MACOSX, внешний README, старый parent delivery folder и flat executable не соответствуют контракту. Notices/licenses находятся в Contents/Resources/Legal, native-test-results/provenance/MANIFEST — в Resources/Build до финальной подписи. Внутренний manifest явно исключает executable, _CodeSignature и себя во избежание circular hashes. Его resource inventory проверяется точно; полный ZIP дополнительно сравнивается со всеми реальными подписанными файлами, modes и symlinks, включая исключённые из manifest. Итоговые executable/ZIP SHA и post-extraction PASS должен фиксировать внешний CI report.

Parser self-test на generated fixtures прошёл: **12 negative Mach-O cases и 7 negative archive cases**. В числе последних — изменение executable или signature, хотя они исключены из внутреннего resource hash scope. Evidence явно помечает native_mac_build=NOT_RUN. Это synthetic parser validation, не выпуск или подписание настоящего плагина.

Production Mac HTTP transport сохраняет ранее проверенный код. Дополнительный native fixture проверяет одновременные реальные UpdateChecker/DonationLinks запросы, два callback contexts/classes, раздельные ответы, отмену каждого owner и quiescence после обоих joins. Проверяющий прочитал эти три фазы и fixture с параллельными handlers; source blocker не обнаружен. Их исполнение на Mac пока pending вместе с десятью обязательными suites и повторным host probe фактически распакованного ZIP на каждой runner-архитектуре.

История, не результат новой версии: Mac 0.3.1 в GitHub Actions run40419330616, commit c3dc36f91ade3c6e5194ffceccd5a009faeab2ae, прошёл native 9/9 на обеих архитектурах, независимый host 1422/0 и package/post-extraction checks. Проверенный Universal ZIP с SHA-256 d916a9fdbc52578769a74ad1e58ee8f5faa7c57dc767548344f4e6ed28e9aedf сохранён. Новый Release 0.4.0 должен получить собственные native evidence, hashes и итоговый вердикт. DAW, интерактивный GUI, target minimum-OS execution, Developer ID и notarization этой подготовкой не подтверждаются.
